# Notes for agents working in BloomLibrary2

## Issue tracker

Work is tracked in the Bloom YouTrack: https://issues.bloomlibrary.org/youtrack

- Ticket ids look like `BL-12345`, and branch names start with the ticket id (e.g. `BL-17000-relogin`).
- Use the `youtrack-api` skill to read cards and post comments on them.
